# 💳 REFUND - Sistema de Gestão de Reembolsos

O REFUND é uma ferramenta corporativa desenvolvida para otimizar e automatizar o processo de solicitação, acompanhamento e aprovação de reembolsos de despesas. O projeto foi projetado para garantir agilidade e controle transparente no fluxo financeiro interno.

---

## 🚀 Tecnologias Utilizadas

O projeto foi construído utilizando as seguintes tecnologias e ferramentas:

- **HTML5 & CSS3:** Estrutura e estilização moderna da interface web corporativa.
- **JavaScript (ES6+):** Linguagem de programação responsável pela lógica da aplicação e manipulação dinâmica do DOM em tempo real.
- **Git & GitHub:** Controle de versão e gerenciamento do ciclo de desenvolvimento do código-fonte.

---

## 📝 Funcionalidades

A aplicação oferece os seguintes recursos:

- **Solicitação de Despesas:** Formulário interativo para o envio de pedidos de reembolso com detalhamento de valores e categorias.
- **Atualização em Tempo Real:** Modificações instantâneas na interface através da manipulação eficiente do DOM com JavaScript.
- **Acompanhamento de Status:** Painel visual para monitorar o andamento das solicitações (pendentes, aprovadas ou rejeitadas).

---

## 📚 Estrutura de Dados
- **Solicitações:** ID do pedido, colaborador, descrição da despesa, valor, comprovante e status atual.
